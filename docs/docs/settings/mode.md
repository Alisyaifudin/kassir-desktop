# Pengaturan

Halaman **Pengaturan** berisi semua konfigurasi aplikasi dengan navigasi sub-halaman.

<!-- TODO: screenshot halaman Pengaturan -->

## Sub-Halaman

| Sub-Halaman | Deskripsi |
|-------------|-----------|
| **Profil** | Profil pengguna dan ganti kata sandi |
| **Toko** | Informasi toko untuk struk |
| **Data** | Manajemen data (ekspor/impor) |
| **Log** | Log aplikasi |
| **Printer** | Pengaturan printer struk |
| **Sinkronisasi** | Sinkronisasi data ke cloud |

## Profil

<!-- TODO: screenshot Profil -->

- Lihat nama akun yang sedang login
- **Ganti Kata Sandi** — ubah kata sandi login

## Toko

<!-- TODO: screenshot Pengaturan Toko -->

Pengaturan yang mempengaruhi tampilan struk:
- **Nama Toko** — muncul di header struk
- **Alamat** — muncul di header struk
- **Header Struk** — teks tambahan di header
- **Footer Struk** — teks di bagian bawah struk (contoh: "Terima Kasih")
- **Tampilkan Kasir** — toggle untuk menampilkan/menyembunyikan nama kasir di struk

## Data

- **Ekspor** — ekspor data ke format CSV
- **Impor** — impor data dari file
- **Hapus Data** — hapus semua data (hati-hati!)

## Log

Menampilkan log aplikasi yang dicatat oleh sistem. Berguna untuk debugging jika ada masalah.

## Printer

<!-- TODO: screenshot Pengaturan Printer -->

- **Pilih Printer** — daftar printer yang tersedia di Windows
- **Lebar Struk** — jumlah karakter per baris untuk format struk

## Sinkronisasi

<!-- TODO: screenshot Sinkronisasi -->

- **Token** — token untuk autentikasi ke cloud API
- **Sinkronkan** — tombol untuk sync manual
- **Status** — status sync per entitas (produk, record, metode, dll)
- **Terakhir Sync** — timestamp sync terakhir per entitas

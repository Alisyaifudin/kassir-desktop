# Analisis

Halaman **Analisis** menyediakan laporan dan grafik performa toko.

<!-- TODO: screenshot halaman Analisis -->

## Sub-Halaman

Analisis memiliki 5 sub-halaman yang bisa diakses dari navigasi tab:

| Sub-Halaman | Deskripsi |
|-------------|-----------|
| **Arus Kas** | Grafik pemasukan vs pengeluaran |
| **Utang** | Pelacakan pelanggan kredit |
| **Laba Bersih** | Analisis keuntungan bersih |
| **Keramaian** | Distribusi penjualan per jam |
| **Produk** | Performa penjualan per produk |

## Pemilih Interval

Semua sub-halaman memiliki pemilih interval waktu:
- **Harian**
- **Mingguan**
- **Bulanan**

Dan pemilih rentang tanggal untuk menentukan periode analisis.

## Arus Kas

<!-- TODO: screenshot Arus Kas -->

Menampilkan grafik batang/garis pemasukan dan pengeluaran dalam periode tertentu. Panel ringkasan menampilkan total pemasukan, total pengeluaran, dan selisih.

## Laba Bersih

<!-- TODO: screenshot Laba Bersih -->

Menampilkan grafik laba bersih (pendapatan dikurangi modal/biaya) dalam periode tertentu. Membantu melihat profitabilitas toko dari waktu ke waktu.

## Keramaian

<!-- TODO: screenshot Keramaian -->

Menampilkan distribusi transaksi per jam dalam bentuk bar chart. Membantu mengidentifikasi jam sibuk toko.

## Utang

<!-- TODO: screenshot Utang -->

Tabel pelanggan dengan status kredit:
- Nama pelanggan
- Total utang
- Sisa utang
- Pembayaran terakhir

Klik kolom untuk mengurutkan data.

## Produk

<!-- TODO: screenshot Analisis Produk -->

Tabel performa per produk:
- Nama produk
- Jumlah terjual
- Total pendapatan
- Total laba

Fitur:
- **Pencarian** — cari produk spesifik
- **Sort** — urutkan berdasarkan kolom
- **Paginasi** — navigasi halaman

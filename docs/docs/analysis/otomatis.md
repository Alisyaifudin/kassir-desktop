# Interval & Rentang Waktu

Semua halaman analisis menggunakan sistem interval yang sama.

## Interval

Pilih cara data dikelompokkan:

- **Harian** — data per hari
- **Mingguan** — data per minggu
- **Bulanan** — data per bulan

Grafik dan ringkasan akan menyesuaikan dengan interval yang dipilih.

## Rentang Tanggal

Gunakan pemilih tanggal untuk menentukan periode analisis:

1. Klik **Dari** — pilih tanggal mulai
2. Klik **Sampai** — pilih tanggal akhir
3. Data akan diperbarui otomatis

## Ringkasan

Setiap halaman menampilkan panel ringkasan dengan angka-angka kunci (total, rata-rata, selisih) yang diperbarui sesuai interval dan rentang yang dipilih.

# Pelanggan

Halaman **Pelanggan** untuk mengelola data pelanggan. Hanya bisa diakses oleh **admin**.

<!-- TODO: screenshot halaman Pelanggan -->

## Daftar Pelanggan

Menampilkan semua pelanggan dengan informasi:
- **Nama** — nama pelanggan
- **Telepon** — nomor telepon

### Tambah Pelanggan

Klik tombol **+** untuk menambah pelanggan baru:
1. Isi **Nama**
2. Isi **Telepon**
3. Klik **Simpan**

### Edit & Hapus

- Klik pelanggan untuk mengedit
- Hapus pelanggan yang tidak diperlukan

## Penggunaan di Transaksi

Saat membuat transaksi di halaman **Toko**, Anda bisa memilih pelanggan yang sudah terdaftar. Data pelanggan akan tercatat di transaksi dan muncul di riwayat.

## Sinkronisasi

Data pelanggan disinkronkan ke cloud backend.

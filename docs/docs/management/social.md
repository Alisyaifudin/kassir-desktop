# Kontak & Sosial

Halaman **Kontak** untuk mengelola informasi toko dan media sosial. Hanya bisa diakses oleh **admin**.

<!-- TODO: screenshot halaman Kontak -->

## Data yang Disimpan

Setiap entri berbentuk key-value:
- **Nama** — label (contoh: "Facebook", "Instagram", "WhatsApp")
- **Nilai** — URL atau teks (contoh: "https://facebook.com/tokosaya")

## Penggunaan

Data kontak bisa digunakan untuk:
- Menampilkan info toko di struk
- Referensi dari halaman pengaturan
- Sinkronisasi ke cloud backend

## Kelola Kontak

- **Tambah** — buat entri baru
- **Edit** — ubah nama atau nilai
- **Hapus** — hapus entri

## Sinkronisasi

Data kontak disinkronkan ke cloud backend.

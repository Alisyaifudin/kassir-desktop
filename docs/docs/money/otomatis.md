# Kategori Change

Kategori dengan tipe **change** dihitung otomatis dari selisih kategori lain.

## Cara Kerja

1. Buat kategori change (contoh: "Pertumbuhan")
2. Kategori ini akan otomatis menampilkan selisih antara total pemasukan dan pengeluaran
3. Nilai diperbarui setiap kali ada entri baru di kategori absolute

:::info
Kategori change tidak bisa diinput manual. Nilainya selalu hasil perhitungan otomatis dari data kategori lain.
:::

## Contoh

Jika Anda memiliki:
- Kategori "Kas" (absolute) — mencatat uang tunai
- Kategori "Pemasukan" (absolute) — mencatat pendapatan
- Kategori "Pengeluaran" (absolute) — mencatat pengeluaran
- Kategori "Laba" (change) — otomatis = Pemasukan - Pengeluaran

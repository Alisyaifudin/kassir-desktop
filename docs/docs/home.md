# Beranda

Halaman **Beranda** adalah dashboard utama yang muncul setelah login.

<!-- TODO: screenshot halaman Beranda -->

## Komponen

### Header
Menampilkan nama toko dan tanggal hari ini.

### Ringkasan Statistik
Menampilkan angka-angka penting:
- Total penjualan hari ini
- Jumlah transaksi hari ini
- Dan statistik relevan lainnya

### Navigasi Utama
Grid ikon untuk akses cepat ke halaman utama:
- **Toko** — buat transaksi baru
- **Stok** — kelola inventori
- **Riwayat** — lihat transaksi
- **Uang** — catat keuangan (admin)
- **Analisis** — laporan performa
- **Pengaturan** — konfigurasi aplikasi

## Navigasi Cepat

Gunakan pintasan keyboard `Alt+0` hingga `Alt+4` untuk berpindah antar halaman utama.

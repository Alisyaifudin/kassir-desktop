## Formulir Produk

Isi data produk:

1. **Nama** (wajib) — nama produk
2. **Barcode** — jika dikosongkan, akan otomatis dibuat (ULID)
3. **Harga Jual** — harga satuan jual
4. **Harga Beli** — modal/capital per unit
5. **Stok Awal** — jumlah stok saat pertama dibuat
6. **Catatan** — opsional

Klik **Simpan** untuk menyimpan produk.

Setelah tersimpan, Anda bisa:
- Upload gambar produk
- Edit informasi produk
- Lihat riwayat stok

## Buat Extra Baru

<!-- TODO: screenshot form extra baru -->

1. **Nama** — nama biaya tambahan
2. **Nilai** — jumlah biaya
3. **Jenis**:
   - `number` — nominal tetap (contoh: Rp 2.000)
   - `percent` — persentase dari subtotal (contoh: 10%)

Klik **Simpan** untuk menyimpan extra. Extra akan tersedia di halaman Toko saat membuat transaksi.

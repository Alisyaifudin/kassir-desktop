# Buat Kasir Baru

Setelah login sebagai admin, Anda bisa menambahkan kasir baru melalui halaman **Kasir** di navigasi utama.

<!-- TODO: screenshot halaman Kasir -->

## Menambah Kasir

1. Klik menu **Kasir** di navigasi
2. Isi formulir:
   - **Nama** — nama kasir untuk login
   - **Role** — pilih `admin` (akses penuh) atau `user` (akses terbatas)
   - **Kata Sandi** — kata sandi untuk login

## Role

| Role | Hak Akses |
|------|-----------|
| **Admin** | Semua halaman termasuk manajemen Kasir, Pelanggan, Metode, Uang, Kontak |
| **User** | Hanya Toko, Stok, Riwayat, Analisis, Pengaturan (tanpa manajemen) |

## Mengedit Kasir

- **Ganti Nama**: Ubah nama tampilan kasir
- **Ganti Role**: Ubah hak akses
- **Ganti Kata Sandi**: Ubah kata sandi login

## Menghapus Kasir

Pilih kasir dan hapus. Akun admin pertama tidak bisa dihapus.

# Riwayat Transaksi

Halaman **Riwayat** menampilkan daftar semua transaksi yang telah selesai.

<!-- TODO: screenshot halaman Riwayat -->

## Daftar Transaksi

Setiap transaksi menampilkan:

- **Tanggal** — kapan transaksi dilakukan
- **Metode** — badge metode pembayaran (Tunai, Transfer, Debit, QRIS)
- **Total** — nilai transaksi
- **Kasir** — nama kasir yang melayani
- **Mode** — indikator Jual (sell) atau Beli (buy)
- **Status Kredit** — jika transaksi kredit

### Filter

Filter transaksi berdasarkan:
- **Rentang Tanggal** — dari/tanggal
- **Metode Pembayaran** — pilih metode tertentu
- **Pelanggan** — nama atau telepon pelanggan
- **Mode** — jual atau beli

## Pencarian Lanjutan

Klik **Cari** untuk membuka pencarian lanjutan dengan filter yang lebih lengkap.

## Detail Transaksi

Klik transaksi untuk melihat detail lengkap:

<!-- TODO: screenshot detail transaksi -->

- **Daftar Produk** — nama, qty, harga satuan, diskon, subtotal
- **Extra** — biaya tambahan yang dikenakan
- **Total** — ringkasan pembayaran
- **Pelanggan** — nama dan telepon (jika ada)
- **Catatan** — catatan transaksi

### Edit Transaksi

Dari halaman detail, Anda bisa:
- **Edit Catatan** — ubah catatan transaksi
- **Ubah Mode** — ganti jual ↔ beli
- **Ubah Metode** — ganti metode pembayaran
- **Tandai Kredit** — tandai transaksi sebagai kredit
- **Bayar Kredit** — catat pembayaran kredit
